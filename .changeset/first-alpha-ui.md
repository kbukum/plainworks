First alpha of the accessible app components built on `elements`: layout, feedback, overlays, display values (including a grouped bar chart with labelled bars and a text summary), navigation, a command palette, theme controls, descriptor-driven forms with schema-rendered fields, keyboard-first rating controls (thumbs, points, A / Equal / B), an app shell with keyboard help, and data views (tables, filters, facets, pagination, comparison, selection, and an inspector pane). Each has its own subpath.
