Add `@plainworks/query` (L2) — a host-independent TanStack Query layer that is the kit's **protocol-agnostic cache substrate**. It never learns a wire format and no transport imports it, so Query stays optional (an RSC + Server Actions host can omit it). The server-safe `.` entry references no host global; the provider lives at a DOM-free `./client` entry (React-without-DOM, so it runs on React Native/Expo too).

- **Per-request client factory** — `createQueryClient` returns a fresh `QueryClient` with no import-time side effects and no module singleton. The host owns client creation: one per SSR request, one at browser startup. `QueryProvider` requires an explicit `client` prop. On React Native/Expo, call `environmentManager.setIsServer(() => false)` once at startup (TanStack detects no-window runtimes as server).
- **Cache routing, one pattern for every protocol** — `writeQueryData` (payload events; an updater returning `undefined` evicts the slot), `invalidateCache` (change-signal events), plus `optimisticUpdate` with a compare-and-set `rollback` on the **write revision** (query object identity + `dataUpdateCount`): the restore runs only while the slot still holds exactly that update's write, so a failed older mutation never overwrites a newer one — even a newer write of an equal value or an eviction followed by a rewrite.
- **Query event sink** — `createQueryEventSink` folds a decoded `PlainEvent` into the cache through the **same** neutral event shape that drives a `channel` `StateSource`: one seam, two sinks (state + query), no bespoke bus. `deliver` honors an `AbortSignal` (re-checked after routing, and cancels in-flight invalidation refetches on abort) and awaits refetches for backpressure.
- **The `remote` state scope** — `createRemoteScope` implements the `state` `Scope`/`StateSource` seam backed by the TanStack cache, so `createScopedState` reaches server-owned state through the unchanged scoped-state surface (`authority: remote`, async, non-durable — the secret guard keeps tokens out). Subscriptions resolve the slot hash through `client.defaultQueryOptions` (so a `queryKeyHashFn` from global *or* per-key `setQueryDefaults` is respected) and pin the slot with a disabled `QueryObserver` so a `setQueryData`-written value survives `gcTime` while subscribed (released on unsubscribe, rebound to the replacement query object after an eviction so a re-written slot stays pinned). `query` (L2) implements the seam `state` (L1) defines; the client is injected at composition, so the L1→L2 direction is never inverted.
- **RSC hydration** — `prefetchQuery`/`prefetchInfiniteQuery` resolve to an explicit `PrefetchOutcome` (`{ status: "warmed" }` or `{ status: "failed", cause }`) instead of rejecting, so a warming failure never aborts server render and the cause is preserved rather than swallowed. TanStack ships only successful queries on dehydration, so a failed prefetch is not sent to the browser. `dehydrateClient` **requires** an explicit `shouldDehydrateQuery` policy (an allowlist is the safe choice) so nothing crosses the server→client trust boundary by default, and mutations are never dehydrated unless a `shouldDehydrateMutation` is supplied explicitly. Plus `hydrateClient` and a re-exported `HydrationBoundary`.
- **List cache keys** — deterministic, order-independent `listQueryKey`/`infiniteListQueryKey` derivation from the shared `ListQueryParams` (filters, `includes`, and `facets` are all canonicalized, so request-set order never changes the key), plus `listQueryOptions`/`infiniteListQueryOptions` helpers for `useQuery`/`useInfiniteQuery` (cursor-paged). Each helper strips control params foreign to its mode (offset drops `cursor`; infinite drops `cursor` and `page`) so keys and fetches never diverge into a collision. The infinite key includes the effective initial cursor (omission normalizes to the empty cursor) so plans at different cursors never collide and identical first pages never split. Every cursor-mode fetch carries an explicit `cursor` — empty on the first page — so a backend can select cursor mode from the very first request. TanStack's abort signal is threaded into every fetch so an abandoned query cancels its request. The wire half lives in `@plainworks/http`.
